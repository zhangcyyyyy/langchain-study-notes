# Git 基础课堂笔记

Git 是分布式版本控制系统。每个本地仓库都保存版本历史，因此开发者可以在离线时查看历史、创建提交和切换分支。

一次普通提交涉及工作区、暂存区和本地仓库。编辑文件后，修改先留在工作区。运行 `git add` 将选定内容放入暂存区。运行 `git commit` 将暂存区中的快照记录到本地仓库。运行 `git status` 可以查看有哪些修改已经暂存、哪些还在工作区。

分支是指向某个提交的可移动指针。可以使用 `git switch -c feature` 创建并切换到新分支，在分支上独立开发。完成后切换到目标分支，再运行 `git merge feature` 合并。若两个分支修改了同一处内容且 Git 无法自动合并，就需要先人工处理冲突，再继续完成合并。
