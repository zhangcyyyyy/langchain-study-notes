# 复习提纲

## 核心概念

- Git 是一种分布式版本控制系统，每个本地仓库都保存有版本历史。
- 一次普通提交涉及工作区、暂存区和本地仓库，编辑文件后需要经过 `git add` 和 `git commit` 才能完成提交。
- 分支是可移动的指针，用于指向某个特定的提交，可以在不同的分支上独立开发和合并代码。

## 自测题

1. Git 是什么类型的版本控制系统？
2. 一次普通提交需要经过哪几个步骤？
3. 如何创建并切换到新分支？

## 参考答案

1. Git 是一种分布式版本控制系统。
2. 一次普通提交需要经过编辑文件、运行 `git add` 将选定内容放入暂存区、运行 `git commit` 将暂存区中的快照记录到本地仓库三个步骤。
3. 可以使用 `git switch -c feature` 创建并切换到新分支。
